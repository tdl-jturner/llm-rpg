# Claude Code Rules

## Committing changes

After completing any code change, always commit it with a descriptive commit message. Do not leave changes uncommitted unless the user explicitly asks to hold off.

## Keeping the README up to date

When making changes that affect user-facing behavior — new features, changed commands, new configuration options, altered defaults, or removed functionality — update [README.md](README.md) to reflect those changes as part of the same commit.
